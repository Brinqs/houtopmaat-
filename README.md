# HoutOpMaatGezaagd: redesign-voorstel

Statisch voorbeeld van een vernieuwde homepage (header, home en footer) voor houtopmaatgezaagd.nl.
Huisstijl (logo, kleuren, fonts Space Grotesk + DM Sans) en content overgenomen van de huidige site.

Openen: `index.html` in de browser.

- `index.html`: pagina
- `styles.css`: stijl (kleuren als CSS-variabelen bovenaan)
- `main.js`: mobiel menu, prijscalculator (indicatie), materiaalfilter
- `img/`: logo, favicon en productfoto's van de huidige site

Let op: reviewteksten zijn placeholders; in productie komen echte Google reviews.
